# Fixture Kit

The Fixture Kit is the sample kit included in the package: an original
Decnet mini modular snap kit on a **2 m grid** with **11 primitive prefabs**.
It exists so your first profile and first build work minutes after import —
and so you can see exactly what a kit folder should look like before pointing
KitForge AI at your own kit.

## The 11 pieces and their roles

- **Structure:** Floor, Wall, Wall Corner, Wall Door, Wall Window, Door Leaf
- **Roof:** Flat, Pitched
- **Props:** Bunk, Crate, Table

![Eleven pieces, every role covered]({{ site.baseurl }}/assets/images/showcase-11.jpg)

Profiling the Fixture Kit reads:

> "11 pieces ready, grid 2 m, 0 warnings"

## Using it

In the Kit section, click **Profile the included Fixture Kit** — or import
the sample from Package Manager (sample name **Fixture Kit**, path
`Samples~/FixtureKit`) and profile its folder with **Profile a Kit**. Then
load the [Sample Outpost]({{ site.baseurl }}/docs/samples/sample-outpost/)
plan and build.

When you move to your own kit, the same rules apply: a kit is a folder of
prefabs, roles are classified from names then geometry, and every role can
be overridden. See [Kit Profiling]({{ site.baseurl }}/docs/kit-profiling/).
