# Getting Started

KitForge AI works in one Editor window and three steps: **profile** a kit,
**plan** a structure, **build** it. This section takes you from the Asset
Store download to your first standing structure.

- [Installation & Setup]({{ site.baseurl }}/docs/getting-started/installation/) — import the package and run the one-click Setup.
- [Quick Start]({{ site.baseurl }}/docs/getting-started/quick-start/) — build the included Sample Outpost end to end.
- [The Home Window]({{ site.baseurl }}/docs/getting-started/home-window/) — what every part of the window does, and how the next-step card guides you.

> **Pro Tip:** You do not need your own modular kit to try KitForge AI. The package ships a complete 11-piece **Fixture Kit** and a ready-made **Sample Outpost** plan, so the first build works minutes after import.
